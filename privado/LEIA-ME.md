# Pasta privada

Tudo nesta pasta (exceto este arquivo) é ignorado pelo Git e **nunca** é publicado no GitHub Pages.

- `financeiro.json`: valores das hospedagens, transportes, pontos e cashback. Abra o site, vá em
  **Financeiro → Importar arquivo** e selecione este arquivo. Os dados ficam somente no navegador
  daquele aparelho (LocalStorage). Repita a importação em cada aparelho que for usar.

Um site estático público com LocalStorage não é um ambiente privado seguro: não guarde aqui
números de cartão, números de reserva ou documentos.
